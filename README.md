# Rogue TUI Game

## Gameplay

### Player: $${\color{magenta}@}$$

- This is you
- You start with 3 lives, if you are hit by an enemy you lose 1 life
- Move with vim motions
- h -> move left; j -> move down; k -> move up; l -> move right;

### Bullets: $${\color{red}\*}$$

- Bullets can be fired with be pressing f
- Bullets will be fired in the last direction player moved

### Walls: \#

- Walls can be destroyed with bullets

### Enemies: $${\color{green}＄}$$

- There are 30 of them each game and they move towards you over time
- Try to shoot all of the enemies before the timer runs out!
- Don't let them reach you!
